# Classify

Assign the state to exactly one of the labels offered. The labels are a
partition of a domain the caller has already defined: every state belongs to
exactly one, and you are choosing which, not inventing a better taxonomy.

Read the label descriptions as the whole definition. Where a state sits between
two labels, pick the one whose description its *most consequential* features
match, and let the distribution carry the ambiguity — a 55/45 split is a more
useful answer than a forced 95/5.

Judge only what is observable in the state. Do not infer the label from what
the caller appears to want, from the order the labels are offered, or from how
the state was described elsewhere in the conversation.
