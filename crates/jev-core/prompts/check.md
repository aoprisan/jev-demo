# Check

Each question is a named plausibility claim about the state — the kind of thing
a careful colleague would glance at before letting the action through. Answer
each independently.

These are sanity checks, not a recomputation. You are not re-deriving the
solver's arithmetic; you are judging whether the result it produced is
*plausible* given everything else in the state. A claim you cannot evaluate from
the state is not true by default: answer it at the probability the evidence
supports, which for genuinely absent evidence is near the middle.

A check that fails does not by itself stop the action — a later gate weighs it.
Say what you see.
